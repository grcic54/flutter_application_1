# Preglednik besplatnih igara

## Izvori
 - Orginalna stranica: https://www.freetogame.com/ 
 - Link JSON-a: https://www.freetogame.com/api/games?platform=pc 
 - Podsjetnik za markdown: https://github.com/adam-p/markdown-here/wiki/markdown-cheatsheet 

---

## O aplikaciji
Aplikacija prikazuje popis besplatnih igara i neke osnovne podakte o njima kao: 
 - naslov
 - žanr
 - platformu
 - izadavača
 - razvijača
 - datum izlaska
 - opis

--- 

## Upute za pokretanje
Otvorite terminal u VScode i upišite:
```AppleScript
flutter pub get
flutter run
```

## Animacije
Animacije se koriste u datotekama `list_ekran.dart` i `servis_kartica.dart` 
 - FadeTransition
 - AnimatedScale
